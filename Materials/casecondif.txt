What case is for
Use case 
when you have one value (or tuple/map/result) and you want to execute different code depending on how it matches various patterns.



Syntax and basic examples

case expression do
  pattern1 [when guard] -> result1
  pattern2 [when guard] -> result2
  _ -> fallback
end

Everything Is an Expression

In Elixir, case, cond, if, and with are all expressions that return values. There are no statements. This means you can bind the result of any control flow construct to a variable:

message = case status do
  :ok -> "Success"
  :error -> "Failure"
end
This eliminates the need for mutable variables that get reassigned inside branches.

eg:
case value do
  :a -> "A"
  :b -> "B"
  _  -> "other"   # catch-all
end

Guards can also be used in case:

case value do
  x when is_binary(x) and byte_size(x) > 0 ->
    "non-empty string"

  x when is_binary(x) ->
    "empty string"

  x when is_number(x) and x >= 0 ->
    "non-negative number"
  _ ->
    "something else"
end

Function heads vs case:

	When to prefer pattern-matching in function heads instead

For many cases, Elixir code pushes case logic into function clauses with pattern matching, which can be clearer:

Function Heads:
def handle({:ok, body}), do: {:ok, body}
def handle({:error, reason}), do: {:error, reason}

Case inside function:
def handle(result) do
  case result do
    {:ok, body} ->
      {:ok, body}

    {:error, reason} ->
      {:error, reason}
  end
end
The above both are eq, but recommended is function heads

cond:
cond in Elixir is a control structure for checking multiple "boolean conditions" and running the code for the first truthy one. It’s used when you have several unrelated conditions rather than matching the shape of a single value


Syntax
cond do
  condition1 -> result1
  condition2 -> result2
  condition3 -> result3
  true -> fallback_result
end

Conditions are evaluated top to bottom.
The first condition that is not nil or false (i.e., truthy) wins.
If no condition matches and there’s no true fallback, Elixir raises a CondClauseError.

egL
age = 17

message =
  cond do
    age < 0 -> "Invalid age"
    age < 13 -> "Child"
    age < 18 -> "Teen"
    age < 65 -> "Adult"
    true -> "Senior"
  end

# => "Teen"

Here each branch is a different boolean expression; cond picks the first true one.

Truthy vs falsy in Elixir
Falsy: only false and nil.

Truthy: everything else (numbers, strings, empty lists, empty maps, atoms other than false, etc.).

status = 404

response =
  cond do
    status >= 200 and status < 300 -> :success
    status >= 400 and status < 500 -> :client_error
    status >= 500 -> :server_error
    true -> :unknown
  end

 temperature = 35

 cond do
   temperature > 40 -> "extremely hot"
   temperature > 30 -> "hot"
   temperature > 20 -> "comfortable"
   temperature > 10 -> "cool"
   true -> "cold"
 end

If and Unless
In Elixir, if and unless are the simplest control structures: they handle a single condition with two possible branches

if:
syntax:
if condition do
  # runs when condition is truthy
else
  # runs when condition is falsy (nil or false)
end

eg:
count=1

if count > 0, do: "Has items", else: "Empty"

unless:
	unless is the inverse of if: the do block runs when the condition is falsy, and else runs when it’s truthy.

unless condition do
  # runs when condition is falsy
else
  # runs when condition is truthy
end

age=10
iex(20)> unless age >= 18, do: "Minor", else: "Adult"
"Minor"

When to use if/unless vs case/cond?

1.Use if/unless for a single condition with two outcomes.
2.Use cond for multiple boolean conditions.
3.Use case to match a single value against different patterns (tags, tuple shapes, map keys).
